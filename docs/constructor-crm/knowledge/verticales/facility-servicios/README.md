# Vertical facility servicios

Aqui van los aprendizajes del vertical facility, limpieza y servicios con relevamiento fisico.

## Posibles reutilizaciones

- limpieza;
- mantenimiento;
- fumigacion;
- seguridad;
- jardineria.

## Campos tipicos

- `tipo_servicio`
- `frecuencia`
- `superficie_m2`
- `cantidad_pisos`
- `cantidad_banos`
- `horario_operacion`
- `zonas_criticas`
- `requiere_visita`

## Regla

Casa Limpia real no debe mezclarse con la base madre. El aprendizaje del vertical si puede preservarse aqui como conocimiento reusable.
