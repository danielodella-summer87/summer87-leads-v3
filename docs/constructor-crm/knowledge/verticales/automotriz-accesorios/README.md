# Vertical automotriz accesorios

Aqui van los aprendizajes del piloto Pickup 4x4 y del vertical automotriz relacionado.

## Posibles reutilizaciones

- accesorios;
- talleres;
- concesionarias;
- flotas;
- repuestos.

## Campos tipicos

- `marca`
- `modelo`
- `anio`
- `matricula`
- `tipo_uso`

## Regla

Pickup sirve como aprendizaje automotriz y como futuro preset o template, pero no debe quedar como fallback core del Constructor.
