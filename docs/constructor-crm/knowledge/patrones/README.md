# Patrones reutilizables

Aqui van patrones tecnicos reutilizables del Constructor.

## Ejemplos de patrones esperados

- `crm-package-config-v1`
- `campos-dinamicos-jsonb`
- `generacion-segura-paquetes`
- `borrador-simulacion-aprobacion-humana`
- `seed-minimo-nuevo-entorno`
- `rbac-modos-app`

## Regla

- Un patron explica una solucion reusable.
- Si algo debe copiarse o adaptarse directamente, probablemente ira en `templates/`.
- Si algo solo documenta aprendizaje o criterio, debe quedarse en `knowledge/`.
