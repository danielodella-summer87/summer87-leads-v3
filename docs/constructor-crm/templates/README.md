# Templates del Constructor

`templates/` contiene material copiables o adaptables para futuros paquetes instalables y futuros proyectos cliente.

## Diferencia entre knowledge y templates

- `knowledge/` explica, conserva y enseña.
- `templates/` sirve como base para copiar o adaptar.

## Reglas

- usar sufijo `.example` cuando corresponda;
- no incluir secretos;
- no incluir datos reales de cliente;
- no asumir ejecucion automatica.
