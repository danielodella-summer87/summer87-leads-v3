# Archivo historico congelado

Aqui ira historia operativa congelada del Constructor.

## Ejemplos de contenido esperado

- validaciones cerradas;
- QA antigua;
- checklists viejos;
- ejecuciones puntuales;
- evidencia historica que ya no forma parte del core activo.

## Regla

- archivar no significa borrar;
- no debe usarse como fuente activa salvo investigacion historica;
- cualquier movimiento a esta carpeta debe quedar documentado.
